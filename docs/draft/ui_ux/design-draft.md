## 1. 项目现状

Periplus 是一个基于 Next.js 15 + 高德地图的旅行路线规划平台。

### 1.1 现有页面

| 页面 | 路径 | 功能 |
|------|------|------|
| 首页 | `/` | 路线列表（经典路线 + 已保存路线） |
| 地图页 | `/map` | 地图编辑（侧边栏 RouteEditor + 高德地图） |
| Debug 页 | `/debug` | EXIF GPS 解析上传 |

### 1.2 技术栈

- **框架**：Next.js 15 (App Router)
- **语言**：TypeScript 5 (严格模式)
- **样式**：Tailwind CSS 4 + shadcn/ui
- **地图**：高德地图 JS API 2.0
- **状态**：Zustand
- **数据库**：SQLite (Prisma ORM)
- **测试**：Vitest + Playwright

### 1.3 现有组件

- `RouteCard` — 路线卡片
- `MapContainer` — 地图容器
- `RouteEditor` / `PointList` / `PointForm` — 路线编辑
- `RoutePolyline` / `RouteMarkers` — 地图覆盖物
- `MapRouteLoader` — 路由参数加载路线
- `PhotoUploader` — EXIF GPS 解析上传（最近新增）

## 2. 设计决策（已确认）

### 2.1 目标用户

**个人旅行爱好者** — 自己规划自由行路线，注重探索感和个性化。

### 2.2 品牌调性

**温暖探索风**

- 主色：琥珀色 (`#f59e0b`) / 暖棕 (`#92400e`) / 米白 (`#fef3c7`)
- 气质：像旧地图和旅行日记，亲切、有温度、鼓励探索
- 元素：圆角卡片、柔和阴影、手写风格装饰字体、地图纸张纹理感

### 2.3 暗色模式

**暂不支持**。先专注做好亮色模式，暗色模式后续再说。

### 2.4 页面结构

**单页应用风格 — 参考 Google Maps**

- 地图为全屏底图（高德地图占满整个视口）
- 顶部悬浮搜索栏（圆角搜索框 + 用户头像）
- 左侧浮窗带 Tab 切换，展示卡片列表
- 右下角 FAB 按钮：定位当前位置 + 创建新路线

### 2.5 搜索范围

**全面搜索**：地点（POI）+ 路线名称 + 地点标签/描述

例如搜"沙漠"能找到敦煌、吐鲁番等地点。
