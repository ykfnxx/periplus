修订要点

  • 预设气泡：仅在首次进入或对话为空时显示，开始对话后自动隐藏
  • 用户消息：深色气泡（#2c2416），右对齐，圆角适配内容长度（非全宽）
  • AI 消息：无气泡，无"AI"标签，纯文本流式输出，支持 Markdown 渲染
  • 无分割线：输入框与对话区域无缝衔接，无视觉分隔
  • 面板阴影：整个 WorkbenchShell 外围有阴影，圆角设计
  • Markdown 渲染：AI 返回内容使用 react-markdown 或类似方案渲染

Markdown 渲染方案

推荐使用 react-markdown + remark-gfm：

  • 支持标准 Markdown（标题、列表、粗体、斜体、代码块、链接）
  • GFM 扩展支持表格、任务列表、删除线
  • 可自定义组件映射：code → 语法高亮、ul/ol → 自定义列表样式
  • 流式输出时支持增量渲染，无需等待完整响应
