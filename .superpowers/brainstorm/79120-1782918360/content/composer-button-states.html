Composer Button State Transition

Send button becomes Stop button during AI generation

Normal State (isDraftLocked = false)
AI Generating State (isDraftLocked = true)

Behavior

  • Normal: Save button (disk) + Send button (paper plane, russet bg)
  • Generating: Save button hidden, Send button becomes Stop button (square, ink bg)
  • Double Esc: Global keyboard listener, double-tap within 500ms triggers cancel
  • Visual feedback: Input area dims slightly when disabled
