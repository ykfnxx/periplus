🔄 Agent-Native 人机协作循环
👤 用户意图
自然语言 / 地图圈选 / 表单填写
↓
🧠 Agent 理解 & 结构化
LLM 解析意图 → 提取约束条件 → 生成结构化规划
↓
🗺️ 可视化呈现（地图 + UI）
路线渲染、景点卡片、时间轴、预算 breakdown
↓
✋ 人类反馈 & 订正
拖拽调整顺序、删除/添加景点、修改天数、圈选替代方案
↓
🔄 Agent 重新优化
接收反馈 → 局部重算 / 全局重排 → 更新规划
↻ 循环直到满意

🎛️ 交互式反馈的具体形式

🎯

地图直接操作

拖拽景点改变顺序、在地图上圈选"不去这里"、点击地图空白处"添加新景点"、调整路线走向

💬

对话式反馈

"第三天太赶了，拆成两天"、"把京都换成奈良"、"预算控制在8000以内"——Agent 理解并重新规划

🎚️

UI 控件微调

滑块调整预算/天数、开关切换交通方式、下拉选择住宿等级、复选框选择兴趣标签

📊

版本对比 & A/B

Agent 同时生成 2-3 个方案，用户对比选择，选中方案的反馈用于优化 Agent 偏好模型

🧠 Agent 架构示意

🎯 Planner Agent
• 接收：用户意图 + 约束条件
• 调用：地图 API、POI 搜索、交通数据
• 输出：结构化路线（天-景点-交通-时间）
• 状态：规划上下文（planning_context）
🔍 Guide Agent
• 接收：景点/路线查询
• 调用：爬虫、第三方 API、向量搜索
• 输出：结构化攻略（吃住行游购娱）
• 状态：知识库上下文（knowledge_context）
💬 Conversational Agent
• 接收：用户自然语言
• 调用：路由到其他 Agent / 直接回答
• 输出：对话回复 + 结构化指令
• 状态：对话历史（conversation_history）
🏷️ Content Agent
• 接收：图片/视频/文本
• 调用：CV 模型、OCR、LLM
• 输出：地点标注、标签、描述、相册组织
• 状态：内容索引（content_index）
🔄 所有 Agent 共享：用户画像（preferences）、实时上下文（session_context）、长期记忆（memory_store）
