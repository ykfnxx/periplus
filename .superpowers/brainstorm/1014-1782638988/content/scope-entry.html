第一期 UI 范围怎么落地？

当前实现是“首页路线列表 + /map 固定侧边栏”。docs/ui_ux 已倾向 Google Maps 式单页地图。下面三种范围都会使用 Mid-Century Modern 视觉语言，但实现成本和产品重心不同。

Periplus · Search places, routes, notes
A · 推荐

地图即首页

把 `/` 和 `/map` 的体验收束为全屏地图工作台：顶部悬浮搜索，左侧浮窗 Tabs，路线列表、已保存、探索都在浮窗里完成。

最贴合草案 改动最大 产品感最强
Periplus · Routes
B · 保守

两页都重绘，但结构不变

`/` 继续做路线画廊，`/map` 改成复古现代编辑台。更像“先换皮 + 局部交互整理”。

风险最低 少改状态流 割裂感仍在
Periplus · Plan
C · 折中

首页做精选入口，地图做主工作台

`/` 是轻量路线发现/最近路线入口，点击后进入完整地图工作台。比 B 更完整，比 A 少一些路由重构。

分阶段友好 仍有首页价值 范围中等
